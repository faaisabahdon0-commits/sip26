// Week 3 Portfolio Task
Using Processing, make an abstract artwork. It should:

Use at least 3 different primitives,
Use the modulo ('%') operator to create a pattern. You can use it for example to alternate between different shapes or colours.
If you want to, you're welcome to use one of your p5 sketches as a starter. Please make sure to include a reference link if you do.

For Week 3, my goal was to build stronger Processing drawing skills and understand how visual techniques change the feel of a sketch. I started by practicing anti-aliasing to make shapes look smoother, then experimented with blending modes to combine colors in new ways. I also created primitive drawings with lines, ellipses, and rectangles, and finished with `task.pde`, a pop-push interaction sketch to practice motion and user input. These steps helped me learn how to use drawing, layering, and interactivity together to make a more polished result.
