// REFLECTION
For Week 4, my goal was to explore procedural noise and image filtering to make visuals look more natural. I started by building a 1D noise sketch, learning how `noise()` and smooth curves can create organic motion. Then I moved to a 2D noise sketch, adding a second dimension of randomness so the pattern could change over both x and y. Finally, I used the filtering sketch with `filter()` on the Brandy image to practice image processing, learning how pixel-based effects can change the mood of a photo.
